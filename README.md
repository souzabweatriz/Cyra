# Cyra — Inteligência de Dados

Projeto Integrador de CTI Insights — Sprint 2. A Cyra transforma planilhas de clientes em uma interface visual para importação, validação e leitura de indicadores.

## Tecnologias

- Frontend: Vue 3, Vite, Vue Router, Pinia e SheetJS (XLSX)
- Estilos: CSS e Tailwind CSS
- Backend: Spring Boot (mantido pela equipe responsável)

## Executar o frontend

```bash
cd frontend
npm install
npm run dev
```

Abra o endereço exibido pelo Vite. A Home pública está em `/`; as rotas internas são `/dashboard`, `/upload` e `/relatorios`.

## Telas entregues

- Home pública com apresentação das funcionalidades Dashboard, Upload e Relatórios
- Login simulado
- Área interna com Sidebar, Dashboard, Upload de planilhas e Relatórios
- Indicadores demonstrativos antes da primeira importação
